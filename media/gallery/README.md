# media/gallery/: "Off the keyboard" photos

Any number of `.jpg`, `.jpeg`, `.png`, `.webp` or `.avif` photos, any shape. The gallery lays them out in justified rows.

- **Order:** by file name, numbers compared numerically. Prefix a number to set the order: `01-…`, `02-…`.
- **Captions** come from the file name: `01-friday-tennis.jpg` becomes "Friday tennis". The leading number is not shown.
- **No caption:** camera names such as `IMG_2034.jpg` or `PXL_20260801_123456.jpg` get none.

Turn location off before exporting (see `media/README.md`).
