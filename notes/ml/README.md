# notes/ml/: Machine learning notes

Drop PDFs here. Each one appears in the **Machine learning** column of the home page's Notes section automatically.

- **Title** = the file name without `.pdf` and without a leading order number: `01 Linear Regression.pdf` becomes "Linear Regression".
- **Order** = by file name, numbers compared numerically (`2` before `10`).
- After adding or removing notes, run `python3 scripts/build_content_index.py` and commit `content.json`. The live site also finds new files without it.
