Blackwell GEMM: FP32 matrix multiplication from scratch in CUDA

FP32 matrix multiplication (SGEMM) written from scratch in CUDA: seven kernels, each one optimization step, measured against cuBLAS on an RTX 5080 Laptop GPU and a rented NVIDIA B200. Every kernel is checked against cuBLAS before it is timed, and each one was profiled with Nsight Compute at 4096 x 4096.

Vraj Patel · github.com/VrajPatel105/blackwell-gemm

02The seven kernels

  1. 00 · Naive

    One thread per output element, reading straight from global memory.

  2. 01 · Coalesced

    Neighboring threads read neighboring memory, so loads get batched.

  3. 02 · Shared-memory tiling

    Each block copies a tile of A and B into shared memory and reuses it.

  4. 03 · 1D thread tiling

    Each thread computes 8 outputs instead of 1 and keeps its sums in registers.

  5. 04 · 2D thread tiling

    Each thread computes an 8x8 patch, reusing every loaded value 8 times.

  6. 05 · float4 loads

    Loads four floats at a time and stores A transposed so shared-memory reads are vectorized too.

  7. 06 · Warp tiling

    Splits each block's tile between warps, then between the threads of each warp. This was the hardest one.
