      02 · Work

      Six projects, each built from scratch and measured. Open any card for the full write-up, tables and links.

      Paged inference engine

      paged-inference-engine · Aug 2026 · Python, Triton

      A mini vLLM-style server built without referencing vLLM source: block-based paged KV cache, continuous batching scheduler, a FlashAttention-2 Triton kernel that reads and writes through a block table, and INT8 KV cache quantization. Serves GPT-2 small, checked against Hugging Face with a parity harness.

      • Throughput, 1 → 32 concurrent requests (GPT-2 small)82 → 1,030 tok/s
      • vs Hugging Face with KV cache, 32 requests3.5x
      • Prefill vs Hugging Face, log-probwithin ~0.005
      • Honest result: vLLM 0.21.0 is faster, at 32 requests~23x
      Repo: paged-inference-engine Write-up: paged inference engine

      GPU inference stack

      cpp-gpu-inference · Triton, PyTorch

      FlashAttention-2 forward and backward in Triton, LLM.int8()-style INT8 post-training quantization, and a tiled Triton matmul profiled with Nsight Compute. SDPA is still faster at long sequences: causal block-skipping isn't implemented yet.

      • INT8 static memory cut (bitsandbytes 29.3%)46.4%
      • Tiled matmul, N=204860.3% FP32 peak
      • FA-2 peak memory, seq 8192 (matches SDPA)~288 MB
      • L1TEX uncoalesced gap, by tiling43.13% → 3.36%
      Repo: cpp-gpu-inference Write-up: GPU inference stack

      Edge quantization on Snapdragon

      edge-quantization-snapdragon · Qualcomm AI Hub

      A from-scratch 48M-param decoder (6 layers, d_model 512) running 100% on the Galaxy S26 Hexagon NPU. W8A8 is 1.8x faster with 3x less memory, and breaks the model; the sensitivity sweep shows why.

      • FP16 · 260 MB2.5 ms · 99.5% agree
      • W8A16 · 93 MB2.4 ms · 60.9% agree
      • W8A8 · 88 MB1.4 ms · 24.6% agree
      • Perplexity: + LayerNorm outputs in INT8+129%
      Repo: edge-quantization-snapdragon

      Blackwell SGEMM ladder

      blackwell-gemm · Oct 2026 · CUDA · in progress

      A CUDA SGEMM ladder from scratch on the RTX 5080, 10+ kernels from naive to tensor-core mma.sync and CuTe, each profiled with Nsight Compute against cuBLAS. Now on kernel 03: shared-memory / 1D thread tiling.

      • Done01 naive · 02 coalescing
      • Current03 1D thread tiling
      • Per-kernel GFLOP/smeasuring
      Repo: blackwell-gemm

      Modern LLM from scratch

      modern-llm-from-scratch · PyTorch

      The building blocks of a modern LLM, each implemented and tested on its own: RMSNorm, SwiGLU, RoPE, grouped-query attention and mixture-of-experts.

      Repo: modern-llm-from-scratch

      EN–DE transformer

      en-de-transformer · PyTorch

      A 6+6 encoder-decoder (8 heads, d_model 512) trained on 200K Tatoeba EN–DE pairs. It became the substrate for the FlashAttention-2 and INT8 work.
